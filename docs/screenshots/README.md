# MOCKED panel validation screenshots

These images are generated by `cd panel_frontend && npm run test:browser` against a mocked Home Assistant service object. They validate responsive, theme, accessibility, localization, running, failure, results, long-evidence, and horizontal-table presentation only. They are **not** evidence of ESPHome connectivity or physical Modbus hardware support.

Every full-panel capture starts at page scroll top and temporarily makes the sticky header static for the screenshot; the production panel remains sticky at runtime. The browser fixture renders visible stand-in glyphs for `ha-icon`, while Home Assistant supplies the real MDI icons in production.

- `mocked-light-desktop.png` / `mocked-dark-desktop.png`: desktop themes; dark captures the running state with enabled Cancel
- `mocked-360px-help.png` / `mocked-320px-help.png`: narrow detailed-help layouts
- `mocked-validation-desktop.png`: invalid-submit errors and focus state
- `mocked-running.png`: running progress
- `mocked-results-horizontal-table.png`: loaded, sorted table at a narrow viewport with asserted overflow and non-zero horizontal scroll
- `mocked-failed-long-evidence.png`: terminal failure and long in-panel guidance
- `mocked-zh-Hant-panel.png`: Traditional-Chinese panel localization
